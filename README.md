## Sistema de Diseño

Este proyecto incluye el módulo Sistemas de Diseño, desarrollado con Angular y organizado con una estructura modular.

### Cómo correr el proyecto

1. Instala dependencias con npm i.
2. Ejecuta npm start o ng serve.
3. Abre la aplicación en el navegador que indique Angular.

### Documentación técnica

Para generar la documentación con Compodoc ejecuta npm run compodoc.

### Módulo Sistemas de Diseño

- Explica qué es un sistema de diseño y por qué mejora la consistencia.
- Resume los problemas de no tener una guía visual común.
- Sintetiza la metodología de Diseño Atómico con átomos, moléculas y organismos.
- Muestra los conceptos en una página principal con tarjeta reutilizable y banner de encabezado.
